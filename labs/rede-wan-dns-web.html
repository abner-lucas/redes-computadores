Parâmetros Avaliados no Laboratório (.PKA)

O núcleo de 5 roteadores já está configurado com o protocolo RIP. Para atingir 100% no arquivo .pka, configure os parâmetros abaixo:

Equipamento Endereço IPv4 / Máscara Gateway Padrão Configuração de Serviço / Cliente Pontos
Servidor-DNS 99.1.1.1 / 255.0.0.0 99.2.2.2 Aba Services → DNS: Ativar (On) · abner.com.br → 88.2.2.2 4 pts
Servidor-Web 88.2.2.2 / 255.0.0.0 88.1.1.1 Aba Services → HTTP: Ativo com página HTML personalizada 3 pts
Roteador-Casa-2 WAN: 77.2.2.2 / 255.0.0.0 77.1.1.1 Aba GUI: definir Static DNS 1 = 99.1.1.1 e salvar 1 pt
PC-Casa-1 e PC-Casa-2 192.168.0.100 (via DHCP) 192.168.0.1 Aba Desktop → IP Configuration: mudar para DHCP 2 pts

Etapas Visuais do Laboratório

Abra o arquivo Pratica_02_Rede_WAN_DNS_e_Web.pka no Cisco Packet Tracer e siga as 4 etapas ilustradas abaixo.

0 de 4 etapas concluídas (0%)
  1. Etapa 01 · 4 pts
    1. Clique no Servidor-DNS (canto superior esquerdo) → aba Desktop → IP Configuration.
    2. Preencha IPv4 Address: 99.1.1.1, Subnet Mask: 255.0.0.0 e Default Gateway: 99.2.2.2.
    3. Mude para a aba Services → clique em DNS no menu lateral esquerdo e marque DNS Service: On (os registros abner.com.br e www.abner.com.br apontando para 88.2.2.2 já estão listados).
    Servidor-DNS · Desktop & ServicesDNS Service: ON
  2. Etapa 02 · 3 pts
    1. Clique no Servidor-Web (canto superior direito) → aba Desktop → IP Configuration.
    2. Preencha IPv4 Address: 88.2.2.2, Subnet Mask: 255.0.0.0 e Default Gateway: 88.1.1.1 (porta do Roteador-4).
    3. Na aba Services → HTTP, o serviço Web já está ativo com o arquivo index.html personalizado.
    Servidor-Web · Rede 88.0.0.0/8HTTP Server: ON
  3. Etapa 03 · 1 pt
    1. O Roteador-Casa-1 já entrega o DNS 99.1.1.1 via DHCP, mas o Roteador-Casa-2 está com o campo DNS zerado.
    2. Clique no Roteador-Casa-2 (lado direito inferior) → abra a aba GUI.
    3. Role até a seção Network Setup → DHCP Server Setting e preencha Static DNS 1: 99.1.1.1.
    4. Role até o fim da tela azul e clique no botão Save Settings.
    Roteador-Casa-2 · Aba GUIStatic DNS 1: 99.1.1.1
  4. Etapa 04 · 2 pts
    1. Clique em PC-Casa-1 → aba Desktop → IP Configuration → selecione DHCP.
    2. Clique em PC-Casa-2 → aba Desktop → IP Configuration → selecione DHCP.
    3. Ambos os PCs receberão IP 192.168.0.100, Gateway 192.168.0.1 e DNS 99.1.1.1, atingindo 100% (10/10 pontos)!
    4. Abra o Web Browser em qualquer um dos PCs, digite abner.com.br ou www.abner.com.br e clique em Go.
    PC-Casa-1 / PC-Casa-2 · Web BrowserHTTP 200 OK
