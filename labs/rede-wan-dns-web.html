Criação de Rede WAN com Servidor Web e DNS

Construção de uma infraestrutura completa de provedor (WAN) interligando 9 sub-redes Classe A (11.0.0.0/8 a 99.0.0.0/8) com um anel de 5 roteadores em fibra óptica usando protocolo RIP, um Servidor DNS traduzindo o domínio abner.com.br, um Servidor Web HTTP e duas redes domésticas com roteadores Wi-Fi e DHCP.

  • 5 Roteadores (Fibra + RIP)
  • 2 Servidores (DNS + HTTP)
  • 2 Switches de Borda
  • 2 Roteadores Residenciais + 2 PCs

Baixar Rede Completa (DNS + Web)

Arquivo revisado via engenharia reversa: todos os dispositivos traduzidos para o português e DNS 99.1.1.1 corrigido em ambos os roteadores residenciais (Casa 1 e Casa 2).

Roteiro Guiado de Configuração (Sem Código CLI)

Siga as 6 etapas abaixo clicando apenas nas abas visuais do Packet Tracer.

0 de 6 etapas concluídas (0%)
  1. Etapa 01
    1. Insira 5 roteadores Router-PT no centro formando um pentágono, 2 switches Switch-PT nos cantos superiores, 2 servidores Server-PT nas pontas superiores (Servidor-DNS à esquerda e Servidor-Web à direita), 2 roteadores sem fio HomeRouter-PT-AC nas laterais inferiores e 2 computadores PC-PT abaixo deles.
    2. Em Connections (⚡), selecione o cabo laranja Fiber (Fibra Óptica) e interligue as portas FastEthernet4/0 e FastEthernet5/0 entre os 5 roteadores conforme o diagrama acima.
    3. Selecione o cabo preto Copper Straight-Through e ligue as portas FastEthernet0/0 dos roteadores de borda aos switches e à porta Internet dos roteadores residenciais.
  2. Etapa 02
    1. Clique em cada roteador (Roteador-0 a Roteador-4) e abra a aba Config.
    2. No menu lateral esquerdo (em INTERFACE), clique nas interfaces conectadas (FastEthernet0/0, FastEthernet4/0 e FastEthernet5/0).
    3. Marque a caixa Port Status: [x] On e digite o endereço IPv4 correspondente da tabela acima (a máscara Classe A 255.0.0.0 é preenchida automaticamente).
  3. Etapa 03
    1. Ainda na aba Config de cada roteador, clique em RIP (abaixo de ROUTING no menu esquerdo).
    2. Digite o endereço de cada rede diretamente conectada àquele roteador no campo Network e clique em Add (por exemplo, no Roteador-0, adicione 11.0.0.0, 22.0.0.0 e 44.0.0.0).
    Por que usar o RIP? Com o protocolo RIP ativo nos 5 roteadores, eles trocam tabelas de rotas automaticamente e descobrem caminhos alternativos pelo anel de fibra óptica!
  4. Etapa 04
    1. Clique no Servidor-DNS → aba Desktop → IP Configuration: defina o IP estático 99.1.1.1, máscara 255.0.0.0 e Default Gateway 99.2.2.2 (que é o IP do Roteador-3).
    2. Vá na aba Services → clique em DNS no menu esquerdo → mude o serviço para On.
    3. Cadastre o domínio principal e seus apelidos:
      • Name: abner.com.br | Type: A Record | Address: 88.2.2.2 → clique em Add.
      • Name: www.abner.com.br | Type: CNAME | Host Name: abner.com.br → clique em Add.
  5. Etapa 05
    1. Clique no Servidor-Web → aba Desktop → IP Configuration: defina o IP estático 88.2.2.2, máscara 255.0.0.0 e Default Gateway 88.1.1.1 (que é o IP do Roteador-4).
    2. Vá na aba Services → HTTP → clique em (edit) ao lado do arquivo index.html.
    3. Personalize o HTML da página (ex.: <center><h1>Ábner Lucas Alves Pereira</h1></center>) e clique em Save.
  6. Etapa 06
    1. Clique no Roteador-Casa-1 → aba GUI:
      • Em Internet Setup, mude Internet Connection Type para Static IP.
      • Preencha Internet IP Address: 11.1.1.1, Subnet Mask: 255.0.0.0 e Default Gateway: 11.2.2.2.
      • Mais abaixo, em Static DNS 1, digite 99.1.1.1 e clique em Save Settings no fim da página.
    2. Repita no Roteador-Casa-2 → aba GUI:
      • Mude para Static IP com Internet IP Address: 77.2.2.2, Subnet Mask: 255.0.0.0, Default Gateway: 77.1.1.1 e Static DNS 1: 99.1.1.1 → clique em Save Settings.
    3. Nos computadores PC-Casa-1 e PC-Casa-2, vá em Desktop → IP Configuration e marque DHCP (eles receberão IP 192.168.0.100, Gateway 192.168.0.1 e DNS 99.1.1.1).
    4. Abra o Web Browser em qualquer um dos PCs, digite http://abner.com.br ou http://www.abner.com.br e clique em Go para ver a página carregar atravessando toda a WAN!
