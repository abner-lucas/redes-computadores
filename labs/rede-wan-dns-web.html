Avance pelas Etapas do Laboratório 02

Cada etapa abaixo corresponde a uma página da janela de instruções dentro do arquivo Laboratorio_02_Rede_WAN_DNS_e_Web.pka.

0 de 4 etapas cumpridas (0%)
  1. Página 1 do .PKA · 4 pts
    1. Clique em Servidor-DNS → aba Desktop → IP Configuration.
    2. Preencha IP 99.1.1.1, Máscara 255.0.0.0 e Default Gateway 99.2.2.2.
    3. Abra a aba Services → DNS e mude DNS Service para On.
    Servidor-DNS · Desktop & Services+4 Pontos
  2. Página 2 do .PKA · +3 pts
    1. Clique em Servidor-Web → aba Desktop → IP Configuration.
    2. Preencha IP 88.2.2.2, Máscara 255.0.0.0 e Default Gateway 88.1.1.1.
    Servidor-Web · IP Configuration+3 Pontos
  3. Página 3 do .PKA · +1 pt
    1. Clique em Roteador-Casa-2 → aba GUI.
    2. Em DHCP Server Setting, preencha Static DNS 1: 99.1.1.1.
    3. Role até o fim da tela azul e clique em Save Settings.
    Roteador-Casa-2 · Aba GUIStatic DNS 1: 99.1.1.1
  4. Página 4 do .PKA · 100%
    1. Em PC-Casa-1 e PC-Casa-2, renove o DHCP em Desktop → IP Configuration.
    2. Abra o Web Browser, digite http://abner.com.br e clique em Go.
    3. Clique em Check Results → Assessment Items para ver os 10 itens verdes cumpridos!
    PC-Casa-1 / PC-Casa-2 · Web Browser10/10 Cumpridos
