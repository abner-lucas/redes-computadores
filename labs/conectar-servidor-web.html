Conectar-se a um Servidor Web

Configure o endereço IPv4, a máscara de sub-rede e o Gateway Padrão do PC-Cliente para que seus pacotes consigam atravessar o Roteador-Central (Cisco 2811), alcançar a sub-rede remota 172.33.100.0/24 via ping e carregar a página HTML hospedada no Servidor-Web.

Avance pelas Etapas do Laboratório 04

Cada etapa abaixo corresponde a uma das 3 páginas da janela de instruções dentro do laboratório no Cisco Packet Tracer.

0 de 3 etapas cumpridas (0%)
  1. Etapa 1
    1. Clique em PC-Cliente → guia Desktop → IP Configuration.
    2. Em Static, preencha:
      • IPv4 Address: 192.168.1.100
      • Subnet Mask: 255.255.255.0
      • Default Gateway: 192.168.1.1
    PC-Cliente · Desktop → IP Configuration3/3 Itens (100%)
  2. Etapa 2
    1. Feche a janela de IP e abra o Command Prompt no PC-Cliente.
    2. Digite ping 172.33.100.50 e pressione Enter.
    3. Confirme o recebimento das respostas com TTL=127 vindas do Servidor-Web.
    PC-Cliente · Command PromptICMP Echo Reply
  3. Etapa 3
    1. Abra o Web Browser na guia Desktop do PC-Cliente.
    2. Digite 172.33.100.50 na barra de URL e clique em Go.
    3. Clique em Check Results → Assessment Items na janela da atividade para conferir os 3 itens verdes cumpridos!
    PC-Cliente · Web Browser3/3 Cumpridos (100%)
