Conectar-se a um Servidor Web

Configure o endereço IPv4, a máscara de sub-rede e o Gateway Padrão do computador cliente (PC0) para que seus pacotes consigam atravessar o roteador Cisco 2811, alcançar a sub-rede remota 172.33.100.0/24 via ping e carregar a página HTML hospedada no Servidor Web.

Baixar Laboratório Guiado (.PKA)

Reescrito com avaliação automática (3 pontos): valida a configuração de IP, máscara e gateway do PC0 e exibe a página do Servidor Web traduzida para o português.

Etapas Visuais do Laboratório

Abra o arquivo Lab_02_Conectar_Servidor_Web.pka no Cisco Packet Tracer e realize as 3 etapas abaixo.

0 de 3 etapas concluídas (0%)
  1. Etapa 01 · 3 pts (100%)
    1. Clique no computador PC0 → selecione a guia Desktop → clique em IP Configuration.
    2. Com a opção Static marcada, preencha:
      • IPv4 Address: 192.168.1.100
      • Subnet Mask: 255.255.255.0
      • Default Gateway: 192.168.1.1
    3. Assim que preencher os 3 campos, o avaliador do Packet Tracer marcará 100% (3/3 pontos)!
    PC0 · Desktop → IP ConfigurationCompletion: 100%
  2. Etapa 02 · Teste ICMP
    1. Feche a janela de IP e clique em Command Prompt (Prompt de Comando) no PC0.
    2. Digite ping 172.33.100.50 e pressione Enter.
    3. Observe que as respostas chegam com TTL=127 (o pacote sai do PC0 com TTL=128 e perde 1 unidade ao passar pelo Router0).
    PC0 · Command PromptICMP Echo Reply
  3. Etapa 03 · Teste HTTP
    1. Feche o Prompt de Comando e clique em Web Browser na guia Desktop do PC0.
    2. Digite 172.33.100.50 no campo URL e clique em Go.
    3. Veja a página em português ser carregada diretamente do servidor remoto!
    PC0 · Web Browserhttp://172.33.100.50
