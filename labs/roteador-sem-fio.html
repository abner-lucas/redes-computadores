Configurar um Roteador Sem Fio e Clientes

Conecte o Divisor-Coaxial à Televisao e ao Modem-a-Cabo, interligue o Roteador-Sem-Fio ao PC-Escritorio e ao PC-Quarto via cabo Ethernet, limite o DHCP para 10 usuários, defina a senha MyPassword1! e configure o Wi-Fi 2,4 GHz (SSID MyHome com WPA2 Personal) para o Notebook-Sala.

Avance pelas Etapas do Laboratório 03

Cada etapa abaixo corresponde a uma das 4 páginas da janela de instruções dentro do laboratório no Cisco Packet Tracer.

0 de 4 etapas cumpridas (0%)
  1. Etapa 1
    1. Em Connections (⚡), escolha o cabo azul em zigue-zague Coaxial.
    2. Ligue Divisor-Coaxial (Coaxial1) ↔ Modem-a-Cabo (Port 0).
    3. Ligue Divisor-Coaxial (Coaxial2) ↔ Televisao (Port 0) e marque Status: ON na TV.
    Página 1 · Cabeamento Coaxial4/19 Itens (21%)
  2. Etapa 2
    1. Em Connections (⚡), selecione o cabo preto Copper Straight-Through.
    2. Ligue Modem-a-Cabo (Port 1) ↔ Roteador-Sem-Fio (Internet).
    3. Ligue PC-Escritorio (FastEthernet0) ↔ Roteador-Sem-Fio (GigabitEthernet 1).
    4. Ligue PC-Quarto (FastEthernet0) ↔ Roteador-Sem-Fio (GigabitEthernet 2).
    Página 2 · Cabeamento Ethernet8/19 Itens (42%)
  3. Etapa 3
    1. No PC-Escritorio, ative DHCP em Desktop → IP Configuration e acesse 192.168.0.1 no Web Browser (admin / admin).
    2. Aba Setup: mude Maximum number of Users para 10 → Save Settings.
    3. Aba Administration: mude a senha para MyPassword1! → Save Settings.
    4. Aba Wireless: ative 2.4 GHz, mude o SSID para MyHome → Save Settings.
    5. Wireless Security: selecione WPA2 Personal e senha MyPassPhrase1! → Save Settings.
    Página 3 · GUI do Roteador-Sem-Fio15/19 Itens (78%)
  4. Etapa 4
    1. Clique em Notebook-Sala → Desktop → PC Wireless → Connect → escolha MyHome e digite MyPassPhrase1!.
    2. Clique em PC-Quarto → Desktop → IP Configuration e selecione DHCP.
    3. Abra Check Results → Assessment Items para conferir os 19 itens verdes concluídos!
    Página 4 · Notebook-Sala & PC-Quarto19/19 Cumpridos (100%)
