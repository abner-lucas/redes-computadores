Etapas Visuais do Laboratório

Abra o arquivo Lab_01_Roteador_Sem_Fio_e_Clientes.pka no Cisco Packet Tracer e siga os 4 quadros visuais abaixo.

0 de 4 etapas concluídas (0%)
  1. Etapa 01 · 8 pts
    1. Em Connections (⚡), selecione o cabo azul em zigue-zague Coaxial:
      • Coaxial Splitter0 (Coaxial1) ↔ Cable Modem (Port 0)
      • Coaxial Splitter0 (Coaxial2) ↔ TV0 (Port 0) e ligue a TV em ON.
    2. Selecione o cabo preto contínuo Copper Straight-Through:
      • Cable Modem (Port 1) ↔ Home Wireless Router (Internet)
      • Office PC (FastEthernet0) ↔ Home Wireless Router (GigabitEthernet 1)
      • Bedroom PC (FastEthernet0) ↔ Home Wireless Router (GigabitEthernet 2)
    Parte 1 · Cabeamento Coaxial e Ethernet5 Conexões Físicas
  2. Etapa 02 · 3 pts
    1. Clique em Office PC → Desktop → IP Configuration e selecione DHCP (ele receberá IP na rede 192.168.0.x e gateway 192.168.0.1).
    2. Abra o Web Browser do Office PC, acesse 192.168.0.1 e entre com usuário admin e senha admin.
    3. Na aba Setup, mude Maximum number of Users para 10 e clique em Save Settings no fim da página.
    4. Vá na guia Administration, mude Router Password para MyPassword1! nos dois campos, clique em Save Settings e autentique-se com a nova senha.
    Navegador Web · http://192.168.0.1Setup & Administration
  3. Etapa 03 · 4 pts
    1. Ainda na interface Web do roteador, clique na guia Wireless no topo.
    2. Em 2.4 GHz, marque Enable, mude o Network Name (SSID) de Default para MyHome e clique em Save Settings.
    3. Clique na subguia Wireless Security (abaixo de Wireless).
    4. Em 2.4 GHz, selecione WPA2 Personal, digite a senha MyPassPhrase1! no campo Passphrase e clique em Save Settings.
    Guia Wireless → Basic & Security (2.4 GHz)WPA2 Personal
  4. Etapa 04 · 4 pts
    1. Clique no Laptop → aba Desktop → PC Wireless → guia Connect.
    2. Selecione a rede MyHome, clique em Connect, insira a chave MyPassPhrase1! e confirme em Connect.
    3. Clique no Bedroom PC → aba Desktop → IP Configuration e selecione DHCP.
    4. Sua pontuação chegará a 100% (19/19)! Teste abrindo skillsforall.srv no navegador Web de qualquer dispositivo.
    Laptop (PC Wireless) & Bedroom PC (DHCP)Completion: 100%
