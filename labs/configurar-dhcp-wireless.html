Configuração do DHCP em um Roteador Wireless

Adicione 3 computadores à topologia, conecte-os às portas GigabitEthernet do roteador sem fio, altere o endereço da LAN do roteador de 192.168.0.1 para 192.168.5.1 e personalize o escopo do servidor DHCP para iniciar em 192.168.5.126 atendendo até 75 clientes simultâneos.

  • Gateway LAN: 192.168.5.1/24
  • IP Inicial DHCP: 192.168.5.126
  • Máx. Usuários: 75 clientes
  • Correção de Bug: Validação APIPA corrigida

Etapas para Concluir 100% do Laboratório

Abra o arquivo Lab_03_Configurar_DHCP_Roteador_Sem_Fio.pka no Cisco Packet Tracer e siga os 4 passos abaixo.

0 de 4 etapas concluídas (0%)
  1. Etapa 01
    1. No menu inferior esquerdo, clique em End Devices → End Devices e arraste 3 computadores genéricos (PC-PT) para a tela (eles receberão automaticamente os nomes PC0, PC1 e PC2).
    2. Em Connections (⚡), selecione o cabo Copper Straight-Through (Cabo Direto) e conecte:
      • PC0 (FastEthernet0) ↔ DHCP Enabled Router (GigabitEthernet 1)
      • PC1 (FastEthernet0) ↔ DHCP Enabled Router (GigabitEthernet 2)
      • PC2 (FastEthernet0) ↔ DHCP Enabled Router (GigabitEthernet 3)
    3. Clique no botão Fast Forward Time (duas setas verdes no canto inferior esquerdo) para que as luzes laranjas do Spanning Tree fiquem verdes imediatamente.
  2. Etapa 02
    1. Clique em PC0 → guia Desktop → IP Configuration → selecione DHCP (observe que o gateway padrão original é 192.168.0.1).
    2. Abra o Web Browser do PC0, digite 192.168.0.1 na URL e faça login com usuário admin e senha admin.
    3. Na seção Network Setup → Router IP, altere o Local IP Address de 192.168.0.1 para 192.168.5.1.
    4. Role até o fim da página e clique em Save Settings (o navegador dará Request Timeout porque o IP do roteador mudou de sub-rede).
  3. Etapa 03
    1. No PC0, abra IP Configuration, clique em Static e depois novamente em DHCP para renovar o endereço na nova rede 192.168.5.0/24.
    2. Abra o Web Browser do PC0, acesse o novo endereço do roteador 192.168.5.1 e faça login com admin / admin.
    3. Em DHCP Server Setting:
      • Altere o Start IP Address (Endereço IP Inicial) de 192.168.5.100 para 192.168.5.126.
      • Altere o Maximum Number of Users (Número Máximo de Usuários) de 50 para 75.
    4. Role até o final da página e clique em Save Settings.
    5. Volte em IP Configuration do PC0, clique em Static e depois em DHCP: agora ele receberá o primeiro endereço da nova faixa (192.168.5.126)!
  4. Etapa 04
    1. Clique em PC1 → Desktop → IP Configuration → selecione DHCP (ele receberá o IP 192.168.5.127).
    2. Clique em PC2 → Desktop → IP Configuration → selecione DHCP (ele receberá o IP 192.168.5.128).
    3. Confira o indicador de conclusão da atividade: 100% (6/6 pontos)!
    4. Se desejar testar no Command Prompt do PC2, execute ping 192.168.5.1 (roteador), ping 192.168.5.126 (PC0) e ping 192.168.5.127 (PC1).
