Configuração do DHCP em um Roteador Wireless

Adicione 3 computadores à topologia, conecte-os às portas GigabitEthernet do roteador sem fio, altere o endereço da LAN do roteador de 192.168.0.1 para 192.168.5.1 e personalize o escopo do servidor DHCP para iniciar em 192.168.5.126 atendendo até 75 clientes simultâneos.

Etapas Visuais do Laboratório

Abra o arquivo Lab_03_Configurar_DHCP_Roteador_Sem_Fio.pka no Cisco Packet Tracer e siga os 3 quadros abaixo.

0 de 3 etapas concluídas (0%)
  1. Etapa 01 · Topologia
    1. Em End Devices, arraste 3 computadores (PC-PT) para a área de trabalho (eles serão nomeados automaticamente PC0, PC1 e PC2).
    2. Em Connections (⚡), escolha o cabo Copper Straight-Through e ligue a porta FastEthernet0 de cada PC às portas GigabitEthernet 1, 2 e 3 do DHCP Enabled Router.
    3. Clique em Fast Forward Time (⏩) para avançar a convergência do Spanning Tree.
    Parte 1 · Montagem da TopologiaGigabitEthernet 1, 2 e 3
  2. Etapa 02 · 3 pts
    1. Ative DHCP no PC0 (Desktop → IP Configuration), abra o Web Browser, acesse 192.168.0.1 (admin / admin) ou clique direto na aba GUI do roteador.
    2. Em Router IP, mude o Local IP Address para 192.168.5.1 e clique em Save Settings.
    3. Em DHCP Server Setting:
      • Altere Start IP Address para 192.168.5.126
      • Altere Maximum Number of Users para 75
    4. Role até o fim e clique em Save Settings.
    DHCP Enabled Router · Basic Setup192.168.5.1 · Start .126 · Max 75
  3. Etapa 03 · 3 pts (100%)
    1. No PC0, abra IP Configuration, clique em Static e novamente em DHCP (ele receberá o IP 192.168.5.126).
    2. No PC1, abra Desktop → IP Configuration e selecione DHCP (receberá 192.168.5.127).
    3. No PC2, abra Desktop → IP Configuration e selecione DHCP (receberá 192.168.5.128).
    4. A pontuação do laboratório atingirá 100% (6/6 pontos)!
    PC0, PC1 e PC2 · Leases DHCPCompletion: 100%
