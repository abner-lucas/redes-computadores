Configuração do DHCP em um Roteador Wireless

Adicione 3 computadores (PC0, PC1 e PC2), conecte-os às portas GigabitEthernet do Roteador-Sem-Fio-DHCP, altere o IP da LAN do roteador de 192.168.0.1 para 192.168.5.1 e personalize o escopo do servidor DHCP para iniciar em 192.168.5.126 atendendo até 75 clientes simultâneos.

Avance pelas Etapas do Laboratório 05

Cada etapa abaixo corresponde a uma das 3 páginas da janela de instruções dentro do laboratório no Cisco Packet Tracer.

0 de 3 etapas cumpridas (0%)
  1. Etapa 1
    1. Em End Devices, arraste 3 computadores (PC-PT) para a área de trabalho (eles receberão os nomes PC0, PC1 e PC2).
    2. Em Connections (⚡), escolha o cabo Copper Straight-Through e ligue a porta FastEthernet0 de cada PC às portas GigabitEthernet 1, 2 e 3 do Roteador-Sem-Fio-DHCP.
    3. Clique em Fast Forward Time (⏩) para as luzes ficarem verdes.
    Página 1 · Montagem da TopologiaGigabitEthernet 1, 2 e 3
  2. Etapa 2
    1. Clique em Roteador-Sem-Fio-DHCP e abra a aba GUI (ou acesse 192.168.0.1 pelo navegador do PC0 com admin / admin).
    2. Em Router IP, mude o Local IP Address para 192.168.5.1 e clique em Save Settings.
    3. Em DHCP Server Setting, altere Start IP Address para 192.168.5.126, Maximum Number of Users para 75 e clique em Save Settings.
    Página 2 · Roteador-Sem-Fio-DHCP3/6 Itens (50%)
  3. Etapa 3
    1. Em PC0, PC1 e PC2, abra Desktop → IP Configuration e marque DHCP (eles receberão 192.168.5.126, .127 e .128).
    2. Clique em Check Results → Assessment Items para conferir os 6 itens verdes cumpridos!
    Página 3 · PC0, PC1 e PC2 (DHCP)6/6 Cumpridos (100%)
